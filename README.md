# 뱅!

보안관 · 부관 · 무법자 · 배신자. 정체를 숨긴 총잡이들의 서부 카드게임을 웹으로 옮긴 팬 프로젝트다.
4~7명, 사람이 모자라면 봇이 자리를 채운다. 규칙은 Board Game Arena 의 BANG! 기본판(카드 80장 · 인물 16명)을 따른다.

## 화면 (허브의 다른 게임 — 바퀴벌레 포커 · 로보77 — 과 같은 흐름)

타이틀(시작하기 · 규칙 보기) → 방 고르기(수배 전단에 이름 · 새 테이블 · 코드로 입장, 마을 게시판의 열린 테이블)
→ 대기실(자리 7칸 · 봇 앉히기 · 방장 설정 · 초대 링크) → **역할·인물**(역할 카드를 뒤집어 보여 주고 인물 확인/고르기 —
모두 마쳐야 시작) → "보안관 ○○ 님부터" → 판 → 결과(한 판 더 · 떠나기)

- 방장 설정: 인물(무작위 / 두 장 중 고르기 — BGA "Choose characters"), **확장(기본판 / 하이눈 / 한 줌의 카드 / 둘 다 / 둘 중 하나)**,
  부활 카드(유령 마을 · 죽은 자), 최대 인원, 내 턴 시간, 막기 시간, 비공개, 관전
- 채팅은 떠 있는 💬(안 읽은 수 · 미리보기), 표정 🤠, 판 위 말풍선. 새로고침해도 같은 자리(sessionStorage token), 초대 링크 `?r=코드`
- 카드를 누르면 고르고 한 번 더 누르면 쓴다. 못 내는 카드는 서버가 까닭을 알려 준다. 술통은 "술통 쓰기" 단추(BGA)
- 시간이 다 되면 턴은 끝내고 막기는 봇이 대신 고른다(💤 자리 비움). 판 중에 나가면 자리는 봇이 이어받는다
- 소리는 처음엔 꺼져 있다

## 규칙

BGA 의 BANG!(Syarwin/bga-bang, MIT 공개 소스)과 dV Giochi 규칙서 · FAQ(Q01~Q26)를 따른다.
기본판 카드 80장(무늬·숫자까지), 인물 16명, 4~7인. 확장은 BGA 에 있는 두 가지 — **하이눈**(13장, 유령 마을 포함) ·
**한 줌의 카드**(15장, 죽은 자 포함). 이벤트는 보안관의 두 번째 턴부터 보안관 차례마다 한 장씩, 마지막 카드는 끝까지.

## 짜임새

```
public/cards.js    카드 80장(무늬·숫자 원판 그대로) · 인물 · 역할 — 서버와 화면이 같이 쓴다
public/index.html  화면 넷
public/app.js      그리기 · 누르기 · 연출 · 소리
src/engine.js      규칙. 판의 흐름이 제너레이터 하나 — 고를 일이 생기면 요청을 내고 멈춘다
src/bot.js         봇. 누가 누구를 쐈는지로 편을 짐작한다
src/hub.js         방 · 자리 · 관전 · 채팅 · 시계 · 역할/인물 고르기. 연출 시간만큼 봇을 기다리게 한다
src/worker.js      Cloudflare Durable Object 감싸개
server.js          로컬 Node 서버(같은 hub.js)
tools/             제미나이 그림 → public/img (make_assets.py 하나로 다시 만든다, 원본은 raw/ — 저장소에는 안 올림)
```

## 돌려 보기

```bash
npm install
npm test                    # 규칙 48개 · 이벤트 61개 · 봇끼리(확장 섞어) 1000판 · 방 흐름
node server.js              # http://localhost:8860
node server.js 8861 fast    # 봇이 기다리지 않는다
```

## 올리기

```bash
npx wrangler deploy
```

Cloudflare Workers 무료 플랜. 결제 수단을 등록하지 않았으니 한도를 넘어도 요금이 붙지 않고 그날 요청만 거절된다.
대기방 · 방 목록 · 채팅을 한곳에서 들고 있어야 해서 Durable Object 는 하나(main)만 쓴다 — 하루 종일 켜져 있어도
무료 한도(13,000 GB·초 ≈ 28시간) 안이다. 아무도 없으면 타이머까지 멈춰 잠든다.
배포하면 메모리에 있던 판은 사라진다(방도 같이).
