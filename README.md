# 뱅!

보안관 · 부관 · 무법자 · 배신자. 정체를 숨긴 총잡이들의 서부 카드게임을 웹으로 옮긴 팬 프로젝트다.
4~7명, 사람이 모자라면 봇이 자리를 채운다. 규칙은 Board Game Arena 의 BANG! 기본판(카드 80장 · 인물 16명)을 따른다.

## 화면

시작(이름) → **대기방**(열린 방 목록 · 대기방 잡담 · 접속자 수) → **방**(자리 7칸 · 봇 추가/내보내기 · 인원/시간 설정 · 방 채팅) → **판**(BGA 처럼 탁자에 둘러앉은 자리, 아래 손 카드, 오른쪽 기록 · 채팅)

- 카드를 누르면 고르고, 한 번 더 누르면 쓴다. 대상이 필요하면 빨갛게 빛나는 자리를 누른다
- 내 턴 · 막기 시간이 다 되면 턴은 끝내고 막기는 봇이 대신 고른다(💤 자리 비움 — 아무거나 누르면 돌아옴)
- 판 도중 나가면 그 자리는 봇이 맡고, 같은 방 번호로 다시 들어오면 자리로 돌아온다
- 판이 돌고 있는 방에 들어가면 구경. 끝나면 방장이 "다시 하기"

## 짜임새

```
public/cards.js    카드 80장(무늬·숫자 원판 그대로) · 인물 · 역할 — 서버와 화면이 같이 쓴다
public/index.html  화면 넷
public/app.js      그리기 · 누르기 · 연출 · 소리
src/engine.js      규칙. 판의 흐름이 제너레이터 하나 — 고를 일이 생기면 요청을 내고 멈춘다
src/bot.js         봇. 누가 누구를 쐈는지로 편을 짐작한다
src/hub.js         대기방 · 방 · 채팅 · 시계. 소켓이 무엇인지 모른다
src/worker.js      Cloudflare Durable Object 감싸개
server.js          로컬 Node 서버(같은 hub.js)
tools/             제미나이 그림 → public/img (make_assets.py 하나로 다시 만든다, 원본은 raw/ — 저장소에는 안 올림)
```

## 돌려 보기

```bash
npm install
npm test                    # 규칙 38개 · 봇끼리 1000판 · 대기방 흐름
node server.js              # http://localhost:8860
node server.js 8861 fast    # 봇이 기다리지 않는다
```

## 올리기

```bash
npx wrangler deploy
```

Cloudflare Workers 무료 플랜. 결제 수단을 등록하지 않았으니 한도를 넘어도 요금이 붙지 않고 그날 요청만 거절된다.
대기방 · 방 목록 · 채팅을 한곳에서 들고 있어야 해서 Durable Object 는 하나(main)만 쓴다 — 하루 종일 켜져 있어도
무료 한도(13,000 GB·초 ≈ 28시간) 안이다. 아무도 없으면 타이머까지 멈춰 잠든다.
배포하면 메모리에 있던 판은 사라진다(방도 같이).
