## 2. 흐름 (허브 표준 — 바퀴벌레 포커 · 로보77 과 같다)

타이틀(시작하기) → 방 고르기(이름 · 새 테이블 · 코드 · 마을 게시판의 열린 테이블) → 대기실 → 역할·인물(`phase: intro`) → 관문 → 판(`playing`) → 결과(`over`) → 한 판 더 / 떠나기

- 1차판은 사용자에게 퇴짜 맞았다: "시작하자마자 내 카드 확인도 안 끝났는데 총을 쏨", "시작 버튼 없이 이름부터", "입력이 안 보임", "CSS 로만 꾸밈". 지금 판은 이걸 다 고친 2차판
- 판은 역할·인물 화면에서 **모두 확인/고른 뒤에야** 열린다(사람 40초, 봇 1.5~5초). 그 뒤 관문(3.2초) 연출
- 봇은 생각 1.2~2.2초 + 방금 연출 시간(`FX_MS`, hub.js · app.js 에 같은 표)만큼 기다린다. 사람 제한 시간도 연출이 끝난 뒤부터
- 화면은 상태를 줄 세워(`queue`/`pump`) 먼저 그리고 연출을 그 위에 얹는다. 3통 넘게 밀리면 연출을 건너뛴다
- 대기실 설정(방장): 인물 무작위/두 장 중 고르기 · 확장(없음/하이눈/한 줌/둘 다/둘 중 하나) · 부활 카드 · 최대 인원 · 내 턴 시간(30/60/90/무제한) · 막기 시간(15/20/30) · 비공개 · 관전 허용. 봇 앉히기 · 내보내기 · 방장 넘기기
- 채팅은 떠 있는 💬(그림 아이콘), 이모티콘 반응, 관전, token 재접속(끊김 6초 유예, 그동안 봇이 대신), `?r=코드` 초대 링크
- 시간이 다 되면 봇이 대신 두고 "돌아왔어요" 단추가 뜬다

## 4. 규칙 근거와 구현 범위

근거: **BGA 공개 소스** https://github.com/Syarwin/bga-bang (MIT) — 애매하면 여기를 본다. 그다음 dV Giochi 규칙서 · FAQ(Q01~Q26).

- **기본판**: 카드 80장, 인물 16명, 역할 4가지(4~7인 구성), 거리 · 사거리 · 뱅! 한 번 · 무기 · 술통 · 다이너마이트 · 감옥 · 잡화점 · 결투 · 기관총 · 인디언 등 전부
- **하이눈**: 12장 + 마지막 하이눈, 유령 마을 · **한 줌의 카드**: 14장 + 마지막 한 줌의 카드, 죽은 자. 유령 마을 · 죽은 자는 대기실 "부활 카드" 설정
  - "둘 다" 는 섞어서 12장 + 마지막, "둘 중 하나" 는 한 세트를 무작위로
  - 첫 이벤트는 보안관의 두 번째 턴에 뜬다
- **BGA 와 같게 한 것** (원작 종이판 규칙과 조금 다르거나 화면 때문에 정한 것):
  - 술통은 자동이 아니라 단추로 쓴다
  - 손에 카드가 있으면 막을 카드가 없어도 막기를 묻는다(손패를 숨기려고)
  - 럭키 듀크는 두 장 중 직접 고른다
  - 버리기 단계에 취소, 손이 비면 턴 자동 끝
  - 효과 없는 맥주 · 무기 교체는 한 번 더 묻는다
  - 강탈 · 캣 벌로우로 내 앞 카드도 고를 수 있다
  - 더미가 비면 버린 카드를 맨 위까지 다 섞는다
  - 페드로 라미레즈 앞에서 누가 쓰러지면 버린 카드 맨 위에 올 카드를 고른다
  - 인물 "무작위 / 두 장 중 고르기"
  - 설교 중에도 결투에서 뱅!을 "버리는" 것은 된다(FAQ Q06 · BGA Duel.php)
  - 슬랩 상대로 빗나감! 1장 내고 손이 비면 수지가 곧바로 뽑아 이어 막는다
- **일부러 단순하게 한 것**: 시드 케첨 능력은 내 턴과 쓰러질 때만(BGA 와 같음), 갈증 중 인물 뽑기 능력은 끔
- 두 명만 남았거나 목사 이벤트 중에는 쓰러질 때 맥주를 낼 수 없다(화면에 이유를 보여 준다)

  - 브라우저 창이 뒤에 있으면 CSS 애니메이션 · 타이머가 멈춰 스크린샷이 반투명하거나 늦다(실제 화면 문제 아님) — 탭을 앞으로 가져와서 찍는다
  - 사용자 기준: "보고 전 처음부터 끝까지 사람처럼 플레이", 폰 화면(375x812)도 본다

## 6. 그림 만드는 과정

1. 사용자 Chrome 에서 제미나이 채팅(1절 주소)을 열고 같은 채팅에서 이어서 요청한다(화풍 유지). 여러 장은 2x2 격자나 마젠타 바탕 시트로 한 번에
2. 받은 파일(`Downloads\Gemini_Generated_Image_*`)은 **내가 받은 것만** `raw/` 로 옮긴다(다른 게임 세션도 같은 계정을 쓴다)
   - 맥에서 다운로드 없이 받은 방법(2026-10-23): 제미나이 페이지는 CSP 때문에 localhost 로 fetch · form 전송이 막힌다. 대신 페이지에서 `img` 를 canvas 에 그려 512px 칸 하나씩 화면 왼쪽 위에 1:1 로 띄우고 Claude in Chrome `zoom`(save_to_disk, scale 0.5)로 512x512 그대로 저장한 뒤 네 칸을 1024 격자로 다시 붙여 `raw/` 에 넣었다. 제미나이 미리보기 이미지가 1024 원본이라 워터마크 위치(`dewatermark2`)도 그대로 맞는다
3. 가공
   - `tools/dewatermark2.py` 제미나이 반짝이 워터마크 지우기(역 알파 합성, `dewatermark.py` 보다 흔적 적음)
   - `tools/cut_grid.py` 격자 자르기 · `tools/cut_sheet.py` 마젠타 바탕 시트를 투명 PNG 로
   - `python tools/make_assets.py` 카드 · 인물 · 역할 · 이벤트 / `python tools/make_ui.py` 단추 · 전단 · 로고 · 아이콘 · 효과 · 게시판 — raw 에서 public/img 를 다시 만든다(재현 가능)
   - `tools/contact_sheet.py` 결과를 한 장에 모아 훑어보기
4. 제미나이 이미지 한도가 하루 몇십 장이라 바닥나면 몇 시간 기다려야 한다(다른 세션과 공유)

## 7. 배포와 주의할 점

```
npx --yes wrangler@4.151.3 deploy     # PowerShell 에선 npx.cmd (npx.ps1 실행 정책)
```

- `git push` 만으로는 사이트가 안 바뀐다. 배포는 따로
- **배포하면 진행 중인 방이 모두 끊기고 사라진다**(Durable Object 가 새로 뜬다). 사람이 하고 있을 땐 배포하지 말 것
- 무료 플랜: 한도를 넘어도 요금 0, 그날 요청만 거절된다. DO 는 하나(main), hibernation 안 씀
- wrangler 로그인은 2026-10-22 갱신. 만료되면 사용자에게 `wrangler login` 승인을 받아야 한다
- 커밋은 한국어 한 줄 요약. **`Co-Authored-By` 줄은 넣지 않는다**(사용자 지시 — GitHub 컨트리뷰터에 Claude 가 뜨면 안 된다)
